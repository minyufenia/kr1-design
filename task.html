Задача № 1012. Даны вещественные числа A, B, C. Определить, выполняются ли неравенства A < B < C или A < B > C и какое именно неравенство выполняется.

  • Результат решения задачи:
  • Действие 1:
  • Действие 2:

Примеры для проверки

  • A = 1, B = 2, C = 3 → выполняется A < B < C
  • A = 1, B = 5, C = 3 → выполняется A < B > C
  • A = 5, B = 2, C = 8 → ни одно не выполняется (A не меньше B)
  • A = 1, B = 4, C = 4 → ни одно не выполняется (B равно C)
  • A = −1.5, B = 0.2, C = 0.1 → выполняется A < B > C (дробные и отрицательные тоже работают)
